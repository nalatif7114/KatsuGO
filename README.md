# KatsuGO
KatsuGo adalah platform self-ordering digital berbasis web yang dirancang untuk mengatasi masalah antrean panjang di kantin kampus. Dengan memanfaatkan QR Code di setiap meja, mahasiswa dapat memesan makanan langsung dari smartphone tanpa perlu berdiri mengantri menghemat waktu istirahat dan meningkatkan efisiensi pelayanan kantin.
